# ComfyUI-MiniMax-H3-LongMedia 0.6.63

## Director: общие пресеты камеры

- Создавайте пресет из настроек любого CAMERA-клипа, применяйте его в другом клипе, переименовывайте и обновляйте через `OVERWRITE`, удаляйте через `DELETE`.
- Библиотека хранится в `director_json`, переживает перезагрузку workflow и доступна в новых и существующих CAMERA-клипах.
- Если параметры клипа изменились после применения пресета, статус показывает это до сохранения обновлённого варианта.

## Перегенерация и conditioning

- Смена роли AUDIO-клипа с `diegetic` на `reactive` сама по себе допустима. Она меняет указания для генерации и может инвалидировать TAKE этого клипа.
- Исправлено копирование conditioning: отсутствующие опциональные ветки преобразуются в пустые списки до обработки guider. Отсутствующий обязательный `positive` теперь выдаёт понятную ошибку вместо traceback `'NoneType' object is not iterable`.

Существующие Director workflow совместимы: при отсутствии поля библиотеки камера-пресетов она создаётся пустой.
