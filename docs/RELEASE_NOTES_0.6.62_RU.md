# ComfyUI-MiniMax-H3-LongMedia 0.6.62

Релиз добавляет управление регенерацией отдельных клипов и обратимое объединение соседних клипов в Director.

## Изменения

- Включайте и отключайте GENERATED MAIN-клипы для обычного RUN в контекстном меню, на клипе или в его настройках. Отключённый клип остаётся на таймлайне и использует свой активный TAKE.
- RUN с отключёнными клипами работает только в MultiClip с совместимым активным TAKE для каждого GENERATED-клипа. Если кэш отсутствует или геометрия клипа изменилась, запуск прекращается с причиной; очередь не расширяется скрыто.
- Выделяйте соседние GENERATED-клипы и объединяйте их в один блок таймлайна. Исходные TAKE сохраняются, а Undo или **Restore original clip boundaries** возвращает отдельные клипы без diffusion.
- Настройки объединённого блока сохраняют отдельный RUN-переключатель для каждого исходного клипа.
- Настройки сохраняются в `director_json`; старые документы автоматически считают все клипы включёнными.
