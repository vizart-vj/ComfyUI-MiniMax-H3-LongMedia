# ComfyUI-MiniMax-H3-LongMedia 0.6.61

В этом релизе исправлены два сбоя RefMod, обнаруженные на длинных рендерах Director и при кодировании RefMod. Справочники параметров на русском и английском и руководства Director относятся к пакету 0.6.61.

## Исправления

- **RefMod на длинных последовательностях:** интервальная маршрутизация теперь использует streamed-query INT8 path Comfy Kitchen, когда плотное fused Q/K/V выделение памяти недоступно. K/V остаются глобально квантованными, Q повторно обрабатывается блоками с выравниванием по 128 строк, маски видимости, силы и персонажа сохраняются для каждого запроса. MAIN shot остаётся одним проходом Sampler.
- **Источники RefMod ENCODE:** ENCODE повторно использует исходные медиа, сохранённые через CREATE FROM SOURCES. Импортированный `.safetensors` без исходников остаётся готовым к использованию и больше не предлагает ошибочное VAE-кодирование пути к самому артефакту.

## Примечания

- Для обычной работы оставляйте `sampler_mode=auto`, `memory_mode=auto` и `attention_mode=auto`.
- Живой рендер ComfyUI/GPU при проверке релиза не выполнялся. Проверены синтаксис Python и JavaScript, состав пакета и контракт masked INT8 API установленного Comfy Kitchen.
